# Site Código Profissional

Páginas de venda em HTML estático, uma pasta por produto. Publicação via cPanel (Git Version Control + `.cpanel.yml`).

- `pack-insta-black-friday-express/`: página de vendas do Pack Insta Black Friday Express.
- `.htaccess`: regras do Apache (referência; o arquivo ativo fica em `public_html` e não é sobrescrito pelo deploy).
